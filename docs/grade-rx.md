# Grade Rx

The pilot reuses the Farm Rx sign-in. The configured account sees a **Grade Rx** item near the bottom of the sidebar (under **More** on a phone) after Farm Rx confirms access to a farm it can manage. Other accounts see no Grade Rx item and no Grade Rx card on Fields. The page keeps the `/fields/grade-rx` address because the pinned Grade Rx frame only opens under that exact parent path. When Farm Rx closes the session or clears farm access, it removes the workspace. The frame is first-party Farm Rx code and shares its browser origin, so source updates require review as part of the app. Farm Rx passes only an account and farm storage scope to the frame. The Grade Rx entry checks the same-origin parent route and scope before mounting or reading plans. Opening the static document directly shows a message to open it from Farm Rx. Its compiled files contain no plans or session values.

Grade Rx stores plans on this device under that account and farm. Signing out closes the workspace and keeps the saved plans for the same account to reopen. Browser storage is not an encrypted vault. Use **Save a copy** before clearing browser data, and use **Open file** to bring a plan over from the earlier preview.

## Build the pilot

- For an isolated local test, build the reviewed Grade Rx checkout with `npm run build -- --mode farm-rx`. Set `GRADE_RX_LOCAL_BUILD` to its `dist` directory. Set `VITE_GRADE_RX_PILOT_USER_ID` to the synthetic Farm Rx pilot ID `00000000-0000-4000-8000-000000000001` when running the pilot Playwright test.
- For an approved hosted pilot, configure `VITE_GRADE_RX_PILOT_USER_ID` for the approved Farm Rx account and `GRADE_RX_SOURCE_TOKEN` as a build-time read credential for only the private Grade Rx repository. The build script pins the reviewed source commit, downloads it and installs its locked dependencies without lifecycle scripts. It builds the package with an isolated subprocess environment and publishes only the compiled browser assets. Update the source pin through a reviewed Farm Rx change.
- With the pilot ID unset, Farm Rx shows no Grade Rx entry. With the pilot ID set, a missing or incorrect Grade Rx build fails the deployment.

Pilot proof covers sidebar launch, sign-out, and farm switching in both desktop and phone-sized browsers. The Grade Rx frame receives its own content policy for public map and data services. The Farm Rx page keeps its existing policy.

The private source pinned at `3ee6c0a043ae34e5806a5a82451f8036069f6e92` adds Grade Rx's storm speed-up (reruns in helper workers inside the Grade Rx frame) to the earlier reviewed pin `25c4f8d7623db6034f197a63480e9e4f19124aa7`. Independent Luna and Sol reviews of the change found no new storage, parent-window or network access; Sol's five rounds on the helper code ended with no high-severity findings, and remaining notes are low-impact edge cases (one-job memory budget on very large areas, timer ordering under a long main run). A local Farm Rx build of this pin passed the Fields launch, sign-out and farm-switching browser run on desktop and phone sizes. A source-pin change moves first-party Farm Rx code and must carry the same verification.
